# For Bhu Bhu ❤️

A simple, sweet apology website made with HTML, JavaScript and Tailwind CSS.

## Add your photo

Put your photo in this folder and rename it exactly:

photo.jpg

The photo appears as a Polaroid on the "I'll try harder" page.

## Run it

This is a simple static website, so you do NOT need npm.

Just double-click `index.html`, or run:

open index.html

## Deploy on Vercel

Upload this folder/repository to Vercel as a static site.

No build command is required.

Made with a little help from ChatGPT 🤭❤️

The website opens behind a 4-digit passcode screen. The current passcode is 1625.
